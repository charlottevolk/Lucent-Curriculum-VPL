**This folder contains all code necessary to replicate the human observer results from the paper "The curriculum effect in visual learning"**

First, download the human observer data from the following link: https://drive.google.com/file/d/1TsDIc603M-sgXFLVafUnLZjXdUPHBk47/view?usp=share_link

Put the folder into the data_analysis_code folder before running.

**TO REPRODUCE FIGURES:**

**Fig. 2B:**
1. Run `plot_observer_group_comparison.py`

**Fig. 3A,C,D:**
1. Run `process_data_for_plotting.py`
2. Run `plot_observer_curriculum_analysis.py`
