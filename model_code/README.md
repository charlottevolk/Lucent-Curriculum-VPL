This folder contains all code necessary to replicate the model results from the paper "The curriculum effect in visual learning"

TO RUN WITH A SPECIFIC CURRICULUM:
1. Shuffled curriculum: run train.py with default settings, set:
- dir_list = [[root_dir+'sep_5.0_1.0_combined',0,0.05,5.0],
                [root_dir+'sep_5.0_1.0_combined',0,0.05,1.0],]
- test_dir_list = [[test_root_dir+'sep_1.0',0,0.1,5.0],
                    [test_root_dir+'sep_1.0',0,0.1,1.0],]
2. Sequential curriculum: run train.py with default settings, set:
- dir_list = [[root_dir+'sep_5.0',0,0.05,5.0],
                [root_dir+'sep_1.0',0,0.05,1.0],]
- test_dir_list = [[test_root_dir+'sep_1.0',0,0.1,5.0],
                    [test_root_dir+'sep_1.0',0,0.1,1.0],]
3. Non-sequential baseline curriculum: run train.py with default settings, set:
- dir_list = [[root_dir+'sep_1.0',0,0.05,5.0],
                [root_dir+'sep_1.0',0,0.05,1.0],]
- test_dir_list = [[test_root_dir+'sep_1.0',0,0.1,5.0],
                    [test_root_dir+'sep_1.0',0,0.1,1.0],]
4. No curriculum, just training on individual angle separations: run train.py with default settings except for the following changes:
- sequential = False
- dir_list = [[root_dir+'sep_10.0',0,0.05,10.0],
                [root_dir+'sep_5.0',0,0.05,5.0],
                [root_dir+'sep_2.0',0,0.05,2.0],
                [root_dir+'sep_1.0',0,0.05,1.0],
                [root_dir+'sep_0.5',0,0.05,0.5],]
- test_dir_list = [[test_root_dir+'sep_10.0',0,0.1,10.0],
                    [test_root_dir+'sep_5.0',0,0.1,5.0],
                    [test_root_dir+'sep_2.0',0,0.1,2.0],
                    [test_root_dir+'sep_1.0',0,0.1,1.0],
                    [test_root_dir+'sep_0.5',0,0.1,0.5],]
- trials = range(1,101)
5. Frozen convolutional layers: run train.py with the same settings as training on individual angle separations (#4) but additionally set frozen_conv = True
6. Shuffled curriculum with different easy:hard ratios: run train.py with the same settings as the shuffled curriculum (#1) but:
    a. Run with forced_sequential = True, forced_antisequential = False, and factor ranging from 2.0 to 10.0
    b. Run with forced_sequential = False, forced_antisequential = True, and factor ranging from 2.0 to 10.0
7. Frozen readout using another model's readout subspace: run train.py with the same settings as the non-sequential curriculum (#3) but additionally set frozen_readout = True and specify the directory where the readout subspace should be taken from
