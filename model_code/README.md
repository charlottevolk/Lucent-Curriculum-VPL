**This folder contains all code necessary to replicate the model results from the paper "The curriculum effect in visual learning"**

**TO RUN WITH A SPECIFIC CURRICULUM:**
1. **Shuffled curriculum:** Run `train.py` with default settings, set:
- `sequential = True`
- `dir_list = [[root_dir+'sep_5.0_1.0_combined',0,0.05,5.0],
                [root_dir+'sep_5.0_1.0_combined',0,0.05,1.0],]`
- `test_dir_list = [[test_root_dir+'sep_1.0',0,0.1,5.0],
                    [test_root_dir+'sep_1.0',0,0.1,1.0],]`
- change `base_dir` to the directory where you want the outputs from this curriculum saved

2. **Sequential curriculum**: Run `train.py` with default settings, set:
- `sequential = True`
- `dir_list = [[root_dir+'sep_5.0',0,0.05,5.0],
                [root_dir+'sep_1.0',0,0.05,1.0],]`
- `test_dir_list = [[test_root_dir+'sep_1.0',0,0.1,5.0],
                    [test_root_dir+'sep_1.0',0,0.1,1.0],]`
- change `base_dir` to the directory where you want the outputs from this curriculum saved

3. **Non-sequential baseline curriculum:** Run `train.py` with default settings, set:
- `sequential = True`
- `dir_list = [[root_dir+'sep_1.0',0,0.05,5.0],
                [root_dir+'sep_1.0',0,0.05,1.0],]`
- `test_dir_list = [[test_root_dir+'sep_1.0',0,0.1,5.0],
                    [test_root_dir+'sep_1.0',0,0.1,1.0],]`
- change `base_dir` to the directory where you want the outputs from this curriculum saved

4. **No curriculum, just training on individual angle separations:** Run `train.py` with default settings except for the following changes:
- `sequential = False`
- `dir_list = [[root_dir+'sep_10.0',0,0.05,10.0],
                [root_dir+'sep_5.0',0,0.05,5.0],
                [root_dir+'sep_2.0',0,0.05,2.0],
                [root_dir+'sep_1.0',0,0.05,1.0],
                [root_dir+'sep_0.5',0,0.05,0.5],]`
- `test_dir_list = [[test_root_dir+'sep_10.0',0,0.1,10.0],
                    [test_root_dir+'sep_5.0',0,0.1,5.0],
                    [test_root_dir+'sep_2.0',0,0.1,2.0],
                    [test_root_dir+'sep_1.0',0,0.1,1.0],
                    [test_root_dir+'sep_0.5',0,0.1,0.5],]`
- `num_trials = 100`
- change `base_dir` to the directory where you want the outputs from this curriculum saved

5. **Frozen convolutional layers:** Run `train.py` with the same settings as training on individual angle separations (#4) but additionally set `frozen_conv = True`
- change `base_dir` to the directory where you want the outputs from this curriculum saved

6. **Shuffled curriculum with different easy:hard ratios:** Run `train.py` with the same settings as the shuffled curriculum (#1) but:
    * Run with `forced_sequential = True`, `forced_antisequential = False`, and factor ranging from 2.0 to 10.0
    * Run with `forced_sequential = False`, `forced_antisequential = True`, and factor ranging from 2.0 to 10.0
- change `base_dir` to the directory where you want the outputs from this curriculum saved

7. **Frozen readout using another model's readout subspace:** Run `train.py` with the same settings as the non-sequential curriculum (#3) but additionally set `frozen_readout = True` and specify the directory where the readout subspace should be taken from (shuffled curriculum with easy:hard ratio of 10:1 in the paper)
- change `base_dir` to the directory where you want the outputs from this curriculum saved

**TO RUN TRAINING FOR SUPPLEMENTARY FIGURES**

1. **Run with a different reference orientation**
    * Run train.py with the same settings as for curricula #1-4 and #6 as described above, but set `transfer_condition = ref_ori` and `num_trials = 30`.

2. **Run with a randomly initialized readout**
    * Run train.py with the same settings as for curricula #1-4 and #6 as described above, but set `random_readout = True`.

3. **Training other model backbones**

1. Run `train.py` with the same settings as the individual angle separations (#4) but:
    * Set `model_name` to the name of the backbone you want to use (all options found in the `models` directory, we used 'AlexNet_skip', 'GoogLeNet_skip', and 'EfficientNet_skip')
    * Set `batch_size` to 1
    * Set `frozen_conv = True`
    * Set `random_readout = True`
